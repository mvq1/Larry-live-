# Larry (AI) — live

A public, always-on 3D view of Larry in his simulated island world.
Larry is an AI. This is a live view of him surviving, thinking, and building — not a recording, and not a person.

Watch: https://mvq1.github.io/Larry-live-/

The view is a browser-rendered 3D island. It polls a published snapshot about once a minute, and movement is interpolated so the page still feels live, even when the feed is a minute or two behind.
